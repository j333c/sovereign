- (note) User provided comprehensive vision: simple home server for video/audio streaming, local AI chat/RAG, document management, low-level web admin
- (decision) Feature packaging: official open-source containers with zero-configuration install and update-safe persistent configs
- (decision) System resilience: fast boot, power-loss robust, guarded container environment, internal storage or NAS support
- (decision) Internationalization: launch with English, German, Spanish, French for UI and documentation
- (decision) Commercial roadmap: open-source software stack with later option to sell preconfigured hardware via website
- (insight) Competitive research highlights GPU VRAM collision between Ollama and Jellyfin as major unaddressed gap in Umbrel/CasaOS; Sovereign can differentiate with active GPU arbitration
- (insight) Power-outage resilience requires robust filesystem strategy (e.g. Btrfs/ZFS snapshots or transactional writes) to protect container SQLite/Postgres databases
- (decision) Stakes calibrated: Public / Launch-grade rigor
- (decision) Working mode: Coaching path
- (decision) Entry point: Journey-led (user-first)
- (decision) Discovery: sovereign.local (mDNS) as primary first-contact URL; DHCP fallback
- (decision) Setup Wizard: Network (DHCP/static/Wi-Fi), Storage (local vs NAS), feature selection, notification email, smart home integration handoff
- (decision) Feature UX: Traffic-light health indicators (green/yellow/red), background auto-install, pre-tuned standard configs, direct links to feature UIs
- (decision) DMS & AI Scope Boundary: Ingestion (mobile/IMAP) and analysis are handled natively by the installed software; Sovereign provides API/webhook bridging to Home Assistant
- (decision) Client Ecosystem: Sovereign will write zero custom client apps; all client interactions rely strictly on existing ecosystem apps and standard web browsers
- (decision) Optical Disc Automation: Zero-touch insert-and-walk-away disc ripping, automated metadata retrieval from external databases, auto-eject on completion
- (decision) RAG Architecture: Chat interface directly queries the DMS for document knowledge; zero duplicate storage or manual re-uploading
- (decision) System Resilience: Automatic clean remount and database integrity verification on reboot; power-loss robustness takes priority over raw boot speed
- (decision) Update Lifecycle: Automatic background updates with automated rollback on failed health check, plus manual one-click rollback in admin UI
- (decision) Media Landing Zone: Network share (SMB/NFS) and web upload drop zone for media files with automatic ingestion and metadata enrichment
- (decision) Shared Local AI Service: Local LLM exposes a standardized OpenAI-compatible API; Sovereign auto-configures installed features to use it natively
