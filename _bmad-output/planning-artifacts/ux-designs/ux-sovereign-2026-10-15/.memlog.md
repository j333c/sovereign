- (decision) confirmed sources: prd.md and addendum.md
- (decision) working mode: coaching path
- (direction) visual aesthetic: clean design, minimal distraction, clean UI component library
- (direction) layout constraint: no scrolling on larger screens (single-viewport appliance dashboard), easy vertical scrolling on mobile
- (decision) surfaces: Setup Wizard, Central Dashboard, Boot Diagnostics, Local AI Chat, Family Tablet Card
- (decision) personas: Alex (Media/Tech Lead), Sarah (Records/Finance)
- (decision) brand voice: consumer appliance simplicity, reassuring, calm, zero terminal jargon
- (decision) ui system: shadcn/ui clean component library with Tailwind CSS semantics
- (direction) desktop viewport: 1080p+ single-viewport grid, zero page scrolling; responsive cards flex and fit
- (decision) visual direction: Direction A (Modern Appliance) - crisp light-mode Nordic/Braun minimalism
- (decision) border radius: 8px (rounded-lg) clean component standard
- (decision) status palette: default semantic traffic lights (emerald #10B981, amber #F59E0B, crimson #EF4444)
- (decision) scope boundary: strict separation between Sovereign appliance admin layer and installed third-party software (Jellyfin, Paperless, Open WebUI provide their own UIs)
- (decision) central settings view: dedicated extensible Settings surface linked from admin header to manage hardware, GPU schedule, storage, and installed features
- (decision) extensible service grid: dashboard uses modular card layout designed for dynamic addition of future services
- (decision) media dropzone: standalone lightweight upload page (e.g. /drop) separate from admin dashboard for simple household use without admin clutter
- (decision) external integrations: home automation (Home Assistant) and email handle notifications; Sovereign provides webhook/event delivery without authoring custom sub-admin tablet UIs
- (event) promoted mockups: dashboard.html, dropzone.html, settings.html
