### Diff-Scope Review Lenses

1. **Adversarial Lens (`lens:adversarial`)**
   - *Source:* `cmd/sovereign-daemon/server.go:1113`
   - *Trigger condition:* `GET /api/v1/documents/deadlines` is registered as an unauthenticated route, while `POST /api/v1/documents/deadlines/{id}/dismiss` and `POST /api/v1/documents/deadlines/scan` are authenticated.
   - *Guard snippet:* Wrap `GET /api/v1/documents/deadlines` with `s.requireSetupOrAdmin(s.handleGetDeadlines)`.
   - *Potential consequence:* Any guest device on the home network can query `/api/v1/documents/deadlines` and read private household contract titles, amounts due, and excerpt citations without logging in.
   - *Disposition:* Fix now (Action Item 4.1).

2. **Edge-Case Lens (`lens:edge-case-hunter`)**
   - *Source:* `internal/documents/imap.go:140-185`
   - *Trigger condition:* During IMAP polling over TLS, if the remote mail server presents an untrusted self-signed certificate, polling aborts with TLS handshake error without falling back or exposing an option in Settings.
   - *Guard snippet:* Add an explicit `allow_insecure_tls` boolean in IMAP settings with clear security warning.
   - *Potential consequence:* Users running self-hosted local mail servers with local CA certificates cannot ingest email attachments.
   - *Disposition:* Defer (Action Item 4.2).

3. **Verification Gap Lens (`lens:verification-gap`)**
   - *Source:* `internal/notify/notify_test.go:120-175`
   - *Trigger condition:* Tests verify webhook payload dispatch and MQTT mock connection, but do not verify queue behavior when SMTP mail server connection times out during a deadline digest dispatch.
   - *Guard snippet:* Add test asserting alert dispatch retry queue persists failed dispatches in SQLite without dropping events.
   - *Potential consequence:* A transient network drop during notification dispatch causes a critical contract deadline email to be permanently lost.
   - *Gap shape:* `phantom-exception`
   - *Consumer:* `internal/notify/dispatcher.go:210`
   - *Evidence:* Zero tests assert SMTP connection timeout retry persistence.
   - *Disposition:* Fix now (Action Item 4.3).
