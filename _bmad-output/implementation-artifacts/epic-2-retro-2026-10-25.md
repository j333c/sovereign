### Aggregate Views

1. **Architecture Delta & Layering (`aggregate:arch-delta`)**
   - *Source:* `cmd/sovereign-daemon/server.go:1076-1087`, `internal/supervisor/supervisor.go`, `internal/storage/dropzone.go`

   - *Disposition:* Accept as-is.

2. **God-Class & Size Growth (`aggregate:god-class`)**
   - *Source:* `cmd/sovereign-daemon/server.go` grew from 1,005 to 1,524 lines; `cmd/sovereign-daemon/server_test.go` grew from 1,423 to 2,751 lines; `internal/supervisor/supervisor.go` (959 lines); `internal/supervisor/docker.go` (814 lines).
   - *Observation:* All container lifecycle logic (watchdog debouncing, image pulling, health probing, compose generation) is centralized in `supervisor.go`. While well-tested, the file is rapidly approaching 1,000 lines.
   - *Disposition:* Defer remediation.

3. **Duplication Map (`aggregate:duplication`)**
   - *Source:* `internal/supervisor/jellyfin.go` vs `internal/supervisor/audio.go`
   - *Observation:* Container specification builders for Jellyfin, Navidrome, and Audiobookshelf have repeated volume-mapping and environment-variable boilerplates with slightly varied struct shapes.
   - *Disposition:* Defer -> Refactor into a standardized container spec builder helper.

4. **Spec-to-Implementation Reconciliation (`aggregate:spec-reconciliation`)**
   - *Source:* `spec-2-1-on-demand-container-lifecycle-engine-health-probing.md` vs `internal/supervisor/docker.go`

   - *Disposition:* Full match.

### Diff-Scope Review Lenses

1. **Adversarial Lens (`lens:adversarial`)**
   - *Source:* `cmd/sovereign-daemon/server.go:1078-1079`
   - *Trigger condition:* Handlers for `POST /api/v1/services/{id}/activate` and `POST /api/v1/services/{id}/deactivate` are registered directly without `requireSetupOrAdmin` or `RequireAdmin` middleware.
   - *Guard snippet:* Wrap both routes with `s.requireSetupOrAdmin(s.handleActivateService)` and `s.requireSetupOrAdmin(s.handleDeactivateService)`.
   - *Potential consequence:* Any unauthenticated client on the local network can activate/deactivate core household services or trigger large image downloads.
   - *Disposition:* Fix now (Action Item 2.1).

2. **Edge-Case Lens (`lens:edge-case-hunter`)**
   - *Source:* `cmd/sovereign-daemon/server.go:388-392`
   - *Trigger condition:* If `/var/run/docker.sock` is inaccessible or missing, `NewServer` silently instantiates `NewMockRuntimeEngine()` without logging an error or setting system health to Degraded.
   - *Guard snippet:* Log a structured warning with remediation advice and record `docker_socket_missing` in system telemetry when falling back to mock runtime outside test mode.
   - *Potential consequence:* On a physical host with Docker socket permission issues, the UI reports services as running normally while no real containers exist.
   - *Disposition:* Fix now (Action Item 2.2).

3. **Verification Gap Lens (`lens:verification-gap`)**
   - *Source:* `internal/storage/dropzone_test.go:45-120`
   - *Trigger condition:* Dropzone tests verify valid audio/video magic bytes and invalid file rejection, but do not verify behavior when disk storage capacity is exceeded during an in-flight upload.
   - *Guard snippet:* Add pre-flight free space check against `/data/drop` before accepting upload chunks.
   - *Potential consequence:* An oversized upload can fill the disk partition completely, starving SQLite WAL journal writes.
   - *Gap shape:* `regression-gap`
   - *Consumer:* `internal/storage/dropzone.go:180`
   - *Evidence:* Zero tests assert disk space exhaustion handling during multi-gigabyte media uploads.
   - *Disposition:* Defer to storage maintenance (Action Item 2.3).
