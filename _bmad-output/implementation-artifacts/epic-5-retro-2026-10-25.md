### Diff-Scope Review Lenses

1. **Adversarial Lens (`lens:adversarial`)**
   - *Source:* `cmd/sovereign-daemon/server.go:1135, 1139, 1140, 1152`
   - *Trigger condition:* Routes for `POST /api/v1/ai/personas/active`, `POST /api/v1/ai/rag/search`, `POST /api/v1/ai/rag/query`, and `GET /api/v1/ai/logs` are registered without authentication guards.
   - *Guard snippet:* Wrap all four endpoints with `s.requireSetupOrAdmin`.
   - *Potential consequence:* Unauthenticated devices on the local Wi-Fi can query private household documents via RAG, view full inference logs, and alter active AI personas.
   - *Disposition:* Fix now (Action Item 5.2).

2. **Cross-Story Boundary Clash: HTTP WriteTimeout vs 60s Warm-Up Buffer (`lens:edge-case-hunter`)**
   - *Source:* `cmd/sovereign-daemon/main.go:72` vs `spec-5-3-dynamic-gpu-arbitration-day-night-idle-surrender.md` (Story 5.3 AC)
   - *Trigger condition:* Story 5.3 specifies an extended `>=60s` timeout buffer for daytime model wake-up (`status: "warming_up"`), but `main.go:72` enforces a global `WriteTimeout: 30 * time.Second` on `httpServer`.
   - *Guard snippet:* Exclude `/v1/` inference paths and streaming endpoints from `httpServer.WriteTimeout` (ties directly to Action Item 1.1).
   - *Potential consequence:* Cold-start model loads taking >30 seconds are severed at the TCP transport layer before the gateway's 60s buffer can respond.
   - *Disposition:* Fix now (consolidated with Action Item 1.1 / Action Item 5.3).

3. **Verification Gap Lens (`lens:verification-gap`)**
   - *Source:* `internal/ai/ai_test.go:850-920`
   - *Trigger condition:* Model download tests verify happy path and mock range downloads, but do not assert behavior when storage space falls below `model_size + 5.0 GB` reserve during download initiation.
   - *Guard snippet:* Add test verifying immediate rejection with HTTP 507 Insufficient Storage when free space is under threshold.
   - *Potential consequence:* Downloading a 14 GB model onto a full drive crashes the server before completion.
   - *Gap shape:* `regression-gap`
   - *Consumer:* `internal/ai/models.go:340`
   - *Evidence:* Zero tests assert `model_size + 5GB` storage check failure path.
   - *Disposition:* Fix now (Action Item 5.4).
