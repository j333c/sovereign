## Findings

### Aggregate Views

1. **Architecture Delta & Boundaries (`aggregate:arch-delta`)**
   - *Source:* `cmd/sovereign-daemon/server.go:1049-1070`, `internal/auth/`, `internal/store/`, `internal/storage/`, `internal/ingress/`, `internal/hardware/`
   - *Observation:* Clean dependency decoupling. `internal/store` manages SQLite with WAL mode (`PRAGMA journal_mode = WAL; PRAGMA synchronous = NORMAL;`). Presentation layer (`/web`) has zero direct host mounts or Docker socket bindings, communicating strictly over HTTP REST and SSE to port 8080.
   - *Disposition:* Accept as-is.

2. **God-Class & File Size Growth (`aggregate:god-class`)**
   - *Source:* `cmd/sovereign-daemon/server.go` (1,005 lines at Epic 1 end), `cmd/sovereign-daemon/server_test.go` (1,423 lines), `web/src/app/setup/page.tsx` (1,008 lines).
   - *Observation:* Server routes, handler logic, problem-details formatting, and telemetry loops were consolidated into a single `server.go` file rather than split into sub-controllers (`auth_handler.go`, `storage_handler.go`, etc.).
   - *Disposition:* Defer remediation. File remains maintainable for Epic 1, but trajectory shows severe god-class risk if future epics continue adding handlers directly to `server.go`.

3. **Pattern Divergence & Error Handling (`aggregate:pattern-divergence`)**
   - *Source:* `cmd/sovereign-daemon/server.go:1056` vs `cmd/sovereign-daemon/server.go:1057`
   - *Observation:* Telemetry SSE route is dual-registered as both `GET /api/v1/system/events` and `GET /api/events`. Dual registration provides backward compatibility with Next.js client, but creates divergence with OpenAPI 3.1 specification (`api/openapi.yaml`) which primarily documents the `/api/v1/` prefix.
   - *Disposition:* Accept as-is.

4. **Spec-to-Implementation Reconciliation (`aggregate:spec-reconciliation`)**
   - *Source:* `spec-1-3-power-loss-resilience-reassuring-boot-diagnostics-screen.md` vs `internal/store/boot.go:114`
   - *Observation:* Spec AC requires `<15s` kernel boot to dashboard and automated recovery. Live runtime verification verified that diagnostics mode executes `PRAGMA integrity_check` and marks `mode: operational` in `<250ms` on test SQLite stores, with graceful clean shutdown properly updating `boot_state.json`.
   - *Disposition:* Full match.

### Diff-Scope Review Lenses

1. **Adversarial Lens (`lens:adversarial`)**
   - *Source:* `cmd/sovereign-daemon/main.go:70-73`
   - *Trigger condition:* `http.Server` configures `WriteTimeout: 30 * time.Second` and `ReadTimeout: 30 * time.Second`.
   - *Guard snippet:* Set `WriteTimeout: 0` (or manage timeouts per-handler/middleware) so streaming responses like SSE `/api/events` and large file uploads are not severed after 30s.
   - *Potential consequence:* Clients listening to SSE telemetry disconnect every 30 seconds, triggering continuous browser reconnect churn; slow network clients fail uploads.
   - *Disposition:* Fix now (Action Item 1.1).

2. **Edge-Case Lens (`lens:edge-case-hunter`)**
   - *Source:* `internal/auth/auth.go:420-438`
   - *Trigger condition:* In `CompleteSetup`, if storage initialization or database write partially fails after hashing the password, the appliance state could be left in a half-configured state where `is_configured` is false but user table has rows.
   - *Guard snippet:* Wrap user creation and initial settings inserts in an explicit `db.BeginTx` transaction with rollback on error.
   - *Potential consequence:* Failed initial setup attempt requires manual database deletion to retry setup.
   - *Disposition:* Fix now (Action Item 1.2).

3. **Verification Gap Lens (`lens:verification-gap`)**
   - *Source:* `cmd/sovereign-daemon/server_test.go:45-80`
   - *Trigger condition:* Integration tests instantiate `server.Handler()` directly or via `httptest.NewServer`, neither of which inherits `main.go`'s `http.Server` timeouts.
   - *Guard snippet:* Add integration test exercising server configuration timeouts against an active SSE stream.
   - *Potential consequence:* Timeout regressions in `main.go` remain completely invisible to the automated test suite.
   - *Gap shape:* `regression-gap`
   - *Consumer:* `cmd/sovereign-daemon/main.go:68`
   - *Evidence:* `server_test.go` contains 0 assertions inspecting connection drop behavior under `WriteTimeout`.
   - *Disposition:* Fix now (Action Item 1.3).
