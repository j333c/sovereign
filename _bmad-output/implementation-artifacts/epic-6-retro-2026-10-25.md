### Diff-Scope Review Lenses

1. **Adversarial Lens (`lens:adversarial`)**
   - *Source:* `internal/supervisor/revision.go:180-215`
   - *Trigger condition:* SQLite database snapshot restoration during rollback replaces `/data/state/sovereign.db` while the active database connection pool is open.
   - *Guard snippet:* Close active database handles or execute WAL checkpointing (`PRAGMA wal_checkpoint(TRUNCATE)`) before atomic file replacement during rollback.
   - *Potential consequence:* On systems with active background goroutine writes during rollback, restoring the SQLite file directly could encounter file locks on Windows or leave orphaned WAL shared-memory files (`.db-shm`).
   - *Disposition:* Fix now (Action Item 6.2).

2. **Edge-Case Lens (`lens:edge-case-hunter`)**
   - *Source:* `internal/supervisor/revision.go:120-145`
   - *Trigger condition:* If an upgrade fails and triggers automatic 180s rollback, and the rollback itself encounters an unexpected failure (e.g. out of disk space on backup volume), the supervisor must prevent an infinite rollback loop.
   - *Guard snippet:* Introduce a `max_rollback_attempts` circuit breaker (default: 1) and enter Safe Recovery Mode if rollback execution fails.
   - *Potential consequence:* Repeated failed rollback cycles consume CPU and log bandwidth.
   - *Disposition:* Fix now (Action Item 6.3).

3. **Verification Gap Lens (`lens:verification-gap`)**
   - *Source:* `web/src/components/DestructiveModal.test.tsx`
   - *Trigger condition:* Tests verify confirmation modal blocking on empty input, but do not verify case-sensitivity rules for localized "RESET" text in German, Spanish, or French.
   - *Guard snippet:* Add test verifying `validateConfirmation` accepts both localized and uppercase tokens across all 4 locales.
   - *Potential consequence:* Non-English users typing localized confirmation text could find the button permanently disabled.
   - *Gap shape:* `missing-adoption-gap`
   - *Consumer:* `web/src/components/DestructiveModal.tsx:75`
   - *Evidence:* Test only asserts English `"RESET"` string.
   - *Disposition:* Defer (Action Item 6.4).
