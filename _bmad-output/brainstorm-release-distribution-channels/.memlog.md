- (note) Technique batch announced: 1. Decision Tree Mapping, 2. Worst Possible Idea, 3. The Blast Radius Inversion (invented), 4. The Persona Dial-In (invented)
- (note) Invented technique 1: The Blast Radius Inversion - Map out every safety layer, isolation boundary, and fallback escape hatch that renders catastrophic update failures zero-impact or self-reversing.
- (note) Invented technique 2: The Persona Dial-In - Stress-test the update pipeline, default settings, and notification models against radical home server user extremes.
- (technique) started Decision Tree Mapping
- (idea) install.sh provides binary channel choice between stable and preview during fresh provisioning
- (idea) Installed system provides a dropdown menu in settings to choose from update streams
- (decision) Repository git clone/fetch is the distribution vehicle; daemon checks GitHub once per hour max
- (decision) Selecting Preview channel triggers a DestructiveModal style warning confirming irreversible forward schema migration
- (decision) Unattended updates during maintenance window (3:00 AM) with pre-update snapshot & 180s health check; development on release branches; upstream spoke container versions checked and updated
- (decision) Git-native polling via git ls-remote avoids GitHub REST API rate limits and requires no API tokens
- (decision) Spoke container versions must be explicitly pinned and verified via automated upstream checks rather than floating :latest
- (decision) Development workflow uses release/vX.Y.Z branches with -rc.N pre-release tags pushed to both origin and github remotes
