# Sovereign Home Appliance Guides & Documentation

Welcome to the bundled guides for Sovereign. The documentation is organized into four native launch languages:

- 🇬🇧 [English Guides (EN)](./en/)
- 🇩🇪 [Deutsche Anleitungen (DE)](./de/)
- 🇪🇸 [Guías en Español (ES)](./es/)
- 🇫🇷 [Guides en Français (FR)](./fr/)

Each language folder contains:
1. **Quickstart & Appliance Setup**: Hardware connections, network discovery (`http://sovereign.local`), and the first-run wizard.
2. **Storage & Network NAS**: Local drive pooling under `/data/` and mounting external SMB/NFS network storage.
3. **Media Ingestion & Dropzone**: Adding videos, music, and books via browser drop, network share (`\\sovereign\drop`), or optical discs.
4. **Private Local AI & Document OCR**: 100% on-device AI assistant, zero-telemetry boundary, and Paperless-ngx document parsing.
5. **Power Resilience & Rollback Safety**: Sudden power loss survival with SQLite WAL, and 180-second automatic rollback safety.
